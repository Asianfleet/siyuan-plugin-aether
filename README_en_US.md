# Aether （以太）

Aether —— Where Dialogue Meets Depth.

## 简介

Aether is an LLM-based enhancement plugin designed for SiYuan Note, which supports sidebar conversations, standalone window conversations, and can also directly output content generated by the LLM within SiYuan files (features that deeply integrate with SiYuan will continue to be added).
⚠️ **Note:** Due to personal time constraints, the plugin is not yet fully stable. Before it becomes stable, it may clear personal settings and chat logs, so please save your important information elsewhere in a timely manner.

## Recently Implemented Features

- Added SiYuan Note files to context
- Style optimization
- Image and document input
- Modification and regeneration of message content in conversations
- Custom preset prompts
- Conversation history
