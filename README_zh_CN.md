# Aether （以太）

Aether —— Where Dialogue Meets Depth.

## 简介

Aether 是一个为思源笔记设计的 AI 对话插件，可支持侧边栏对话、独立窗口对话，也可以将 AI 生成的内容插入到思源文件内（将会持续增加与思源深度结合的功能）。

⚠️ 建议及时将重要信息保存到其他地方，以免丢失。

## 开始

[点击查看使用文档](https://gcnicgs9mvik.feishu.cn/wiki/RKKvwo65Yi91e1kWgABcAznontc?from=from_copylink)

✨ 目前已更新至 2.0 版本，新增以下特性：
- 支持 docker 以及 移动端
- 支持后台消息生成（同时生成多条消息）
- 支持 command 与 rules
- 对话内文本划选工具栏
- 对话内容快速跳转、回到顶部、回到底部

未来计划支持：
- sql 查询
- rag 功能
- 对话时联网搜索，思源笔记内搜索
- 智能体
